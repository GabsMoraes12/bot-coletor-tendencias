# Bot Coletor de Tendências e Insights (Web Scraping)

Este projeto apresenta um script automatizado em Python focado em inteligência de mercado e Planejamento de Conteúdo. Utilizando técnicas de *Web Scraping*, o bot minera informações e tópicos quentes diretamente de portais globais de tecnologia e inovação, estruturando esses dados brutos em relatórios analíticos para equipes de marketing e mídias sociais.

---

## Tecnologias e Bibliotecas Utilizadas

* **Python:** Linguagem de programação utilizada para construir a lógica de automação.
* **BeautifulSoup (bs4):** Biblioteca fundamental para analisar documentos HTML e extrair os dados específicos das páginas web.
* **Requests:** Responsável por realizar as requisições HTTP e coletar o código-fonte dos portais analíticos de forma segura.
* **Pandas:** Utilizado para organizar as informações coletadas em matrizes de dados e exportá-las perfeitamente.

---

## Funcionalidades do Projeto

1. **Extração Automatizada (Scraping):** O script acessa portais de relevância global, contorna bloqueios básicos simulando navegação humana (*User-Agents*) e coleta os títulos dominantes do momento.
2. **Data Cleansing & Structuring:** Filtra e organiza os dados coletados, removendo ruídos visuais e preservando apenas o texto de interesse.
3. **Geração de Relatórios de Insights:** Exporta automaticamente um arquivo consolidado (`Tendencias_Mercado_Coletadas.xlsx`) com data e hora da extração, pronto para ser distribuído para analistas de conteúdo e tráfego.

---

## Valor Prático para o Mercado

Em agências de publicidade e departamentos de marketing, monitorar o mercado manualmente consome horas preciosas de trabalho. Este projeto prova a viabilidade de aplicar **ciência de dados para otimizar o monitoramento de tendências**, permitindo que marcas criem conteúdos ou tomem decisões de tráfego pago baseadas em dados coletados em tempo real.

---

## Contexto do Desenvolvimento

Projeto prático desenvolvido para consolidar conceitos de manipulação de requisições, tratamento de estruturas HTML e engenharia de dados aplicada, unindo conhecimentos da graduação em **Ciência da Computação** com demandas reais de **Marketing Digital**.
